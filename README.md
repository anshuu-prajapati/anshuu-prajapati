## 🎙️ GPS Fleet Voice Support Agent

**AI-powered voice calling system for automated fleet/GPS support**

[![GitHub](https://img.shields.io/badge/Repository-0B1020?style=for-the-badge\&logo=github)](https://github.com/anshuu-prajapati/gps-voice-agent)

### What it does

An automated voice agent that calls fleet drivers, understands their responses and determines whether a vehicle requires service or simply needs its status recorded.

### Highlights

* 🎙️ Automated outbound voice calls
* 🧠 LLM-powered reasoning and extraction
* 🇮🇳 Hindi / Hinglish understanding
* 🧩 LangGraph state-machine workflow
* 📍 Technician-location validation
* 🎫 Automated service-ticket creation
* ⚡ One-shot extraction from natural speech
* 📊 Structured service-record generation

### Architecture

```text
Fleet / Vehicle Event
        │
        ▼
   FastAPI API
        │
        ▼
  Twilio Voice Call
        │
        ▼
 Driver Speech
        │
        ▼
 Speech Recognition
        │
        ▼
    LangGraph
        │
        ▼
 Amazon Bedrock / LLM
        │
        ├───────────────┐
        ▼               ▼
Vehicle Status     Service Request
        │               │
        └───────┬───────┘
                ▼
       Structured Records
```

**Stack:** `Python` · `FastAPI` · `Twilio` · `LangGraph` · `Amazon Bedrock` · `Pydantic`
